# -----------------------------------------------------------------------------
# WHY -Dhadoop.home.dir=C:\hadoop is mandatory on Windows:
# Spark bundles Hadoop client libraries even for local[*] execution (used by
# DataFrameWriter for the Hadoop FileSystem abstraction, even against plain
# local disk). On Windows, Hadoop's FileUtil looks for `winutils.exe` and
# `hadoop.dll` under %HADOOP_HOME%\bin to perform POSIX-style file permission
# checks. Without this, you get:
#   java.io.IOException: Could not locate executable null\bin\winutils.exe
#
# SETUP STEPS (one-time, see README.md Section "Windows Prerequisites"):
#   1. Create C:\hadoop\bin
#   2. Download winutils.exe + hadoop.dll matching Hadoop 3.3.6 from:
#      https://github.com/kontext-tech/winutils (community-maintained mirror
#      of the archived steveloughran/winutils repo) - place both files in
#      C:\hadoop\bin
#   3. Add C:\hadoop\bin to your Windows PATH environment variable (System
#      Properties > Environment Variables > Path > New)
#   4. Restart IntelliJ IDEA fully (not just the run config) so it picks up
#      the updated PATH.
# -----------------------------------------------------------------------------
